How to add your own plugins

For other CounterStrikeSharp plugins (install Metamod + CounterStrikeSharp from the list above first):

  1. Open FUNCTION → OPEN SERVER FOLDER — it opens the server's csgo folder.
  2. Go into the plugins folder:
…\csgo\addons\counterstrikesharp\plugins\
  1. Download the plugin and extract it — each plugin is its own folder with a .dll inside.
  2. Drop that folder into plugins\. Any config goes in addons\counterstrikesharp\configs\plugins\.
  3. Restart the server. Check it loaded with css_plugins list in the server console.
